# {{APP_NAME}}

zerocode 应用（小型 · Vue3 + FastAPI）。

- 本机访问（dev 预览）：http://localhost:{{DEV_PORT}}
- 数据库：dev = {{DEV_DB}}，prod = {{PROD_DB}}（由平台自动供给）
- 数据变更：一律写入 `sqlchange/V<日期>_<序号>_<说明>.sql`
- 已应用到库的 `V*.sql` **不得修改也不得删除**（平台按文件名+校验和记账，改了会被拒启动预览）。
- 需要改列类型/拆表/删列时**分两个版本两步走**：第一版加新列并双写，第二版迁数据后删旧列。
- 上架到应用商店后，本应用的迁移序列就是其他实例的升级基线，破坏性变更未走两步会让订阅实例无法升级。
