# prod 段 —— 上线要执行的数据（ADR-0040）

这里的文件只对 `<slug>_prod` 执行，预览库看不见。放**上线必需的初始行**（真实字典、真实菜单与授权、
默认配置），以及与 dev 段内容不同的那部分——dev 里留着演示行，prod 里只留真实必需行。

- **写之前先查线上现状**：聊天页的数据库工具 `db_query(env=prod)` 是只读的，能查已有行；
  照着现状写才不会把线上已有的数据再插一遍，也不会漏掉 dev 里验证过的必要行
- 命名与顶层同一套：`D<YYYYMMDD>_<两位序号>_<说明>.sql`，只追加、不可变、幂等（`ON CONFLICT DO NOTHING`）
- 一经应用不得修改：`sqlchange_history` 按 `prod/<文件名>` 记 checksum，改了就红在 `TAMPER prod/…`
- 执行顺序是「公共段全部 → 本段按文件名升序」
- 演示数据别写这里（测试用户、示例内容进 `../dev/`）；两库内容完全一致的写在 `../` 顶层
