# dev 段 —— 只进预览库的数据（ADR-0039）

这里的文件只对 `<slug>_dev` 执行，`<slug>_prod` 永远看不见。放**演示数据**：测试用户、示例工单、
为了让预览有内容可看而灌的行——它们上线后不该存在，所以别写进顶层。

- 命名与顶层同一套：`D<YYYYMMDD>_<两位序号>_<说明>.sql`，只追加、不可变、幂等（`ON CONFLICT DO NOTHING`）
- 一经应用不得修改：`sqlchange_history` 按 `dev/<文件名>` 记 checksum，改了就红在 `TAMPER dev/…`
- 执行顺序是「公共段全部 → 本段按文件名升序」，所以本段可以依赖顶层建好的表
- 参考数据不放这里：菜单、字典、角色授权、系统参数上线也要生效，去 `../prod/` 配一份，
  或内容一字不差时只写 `../` 顶层。只写 dev 段 = 线上缺这份配置
- 与 `../prod/` 里的文件**可以同名**（两个库各自记账），常见的成对写法就是同名两份、内容不同
