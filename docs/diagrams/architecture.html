ZeroCode 系统架构

一台跑在你自己机器上的 AI 应用工厂 —— 从对话生成，到发布回退，到分发给整个团队

平台后端 :8100 前端 dev :8082 平台库宿主 :5433 应用端口池 8210–8399 容器网 zcnet 连库别名 zerocode-pg16:5432
使用者入口谁在用、用什么地址 全在浏览器里

1平台控制台

  • Vue 3.5 单页：聊天 / 应用 / 商店 / 设置
  • 构建产物由后端托管，同源部署
  • 写代码的全过程都在这里确认

2中央 OpenResty 网关

  • 通配域名 HTTPS 终止
  • routes.json 动态路由，按 mtime 刷新
  • 只有正式态 running 才进路由

3使用者拿到的地址

  • 预览 127.0.0.1:82xx 抽屉内嵌
  • 局域网 http://IP:端口
  • 域名 https://应用名.域名
HTTP /api · WebSocket /ws/chat · /ws/deploy 网关旁路：HTTPS 直达第 4 层正式端口，不经过平台后端
平台服务层成熟 Agent 不管的那一段 本机容器 · :8100

1API 路由 + WS 通道

  • sessions · apps · files · models · config
  • /ws/chat 流式对话与工具事件
  • /ws/deploy 只搬运状态，不解释语义

2部署套件 deploy

  • compose 渲染 · 端口分配 · 建库供给
  • sqlchange 迁移 · 契约与护栏校验
  • 事件广播 + 日志环形缓冲供订阅

3应用商店 store

  • 一键上架 → 申请 → 创始人审批
  • 自动供给完全独立实例（码+库+地址）
  • 升级先在真数据克隆库上预演
会话消息交给 Agent 循环，工具事件回流成卡片 点「发布」→ 部署套件接管
AI 引擎层会写代码的那一段 可换模型，不改流程

1Agent 循环 + 写盘确认

  • 拆任务、逐文件写、执行中可插话
  • 改成什么样，确认后才落盘
  • 每处改动留 diff，可逐条回看

2工具集与上下文

  • 读写 / 检索 / 跑检查 / 库查询
  • ask_user 把歧义摊成选择题
  • @ 引用文件 · 粘原型图 · 一键压缩

3模型解析与记忆

  • OpenAI 兼容多套凭据，按会话切换
  • 是否支持看图可在设置里声明
  • 工作区记忆沉淀约定与坑
确认后的写入落到 应用工作区，数据变更写成 sqlchange 浏览器自检 sidecar :8101 打开预览页验收
生成产物层每个应用独立成套 标准工程，可以带走

1代码工作区 apps/{slug}

  • backend / frontend / sqlchange
  • 独立目录、库、端口，互不干扰
  • 不入库：每台机器各自生成

2dev 预览栈

  • zc-{slug}-dev 容器组
  • 源码挂载 + 热重载，重启即生效
  • 迁移闸门先行，实时日志可订阅

3prod 正式栈

  • zc-{slug}-prod 版本化镜像
  • 旧版本不中断，失败自动回退
  • 健康检查 + 资源监控 + 一键回滚
平台经 Docker Engine 起停栈、建库、跑迁移 四档栈：vue3-fastapi · vue3-node · static · vue3-springboot
运行时与基础设施代码与数据自持 一台机器全栈跑通

1PostgreSQL 16 + pgvector

  • 平台库 + 每应用独立 dev / prod 库
  • 平台 DDL 走 changelog 自动迁移
  • 记忆的语义检索靠 vector 扩展

2Docker · Compose · zcnet

  • dev / prod 两套栈各一组容器
  • 命名卷承载依赖缓存与数据
  • 端口冲突点名占用者后再分配

3Redis 7（大型栈私有）

  • 登录态与缓存基座，开 AOF 不丢
  • 只挂内部网 appredis，不暴端口
  • 配 RBAC 权限体系与 JWT 认证
唯一出机器的动作：把上下文交给 模型 API；产物与数据都留在本地
外部依赖可替换、可私有化

外大模型服务

  • OpenAI 兼容端点，凭据自己填
  • 可指向私有化内网模型
  • 不填凭据时聊天会报连接错误

外镜像源

  • apt / PyPI / npm 三源，出包时烘进包
  • 同一份源管住平台与它起出的每个栈
  • 直连不动时问答里现场改

外域名与证书

  • 通配域名 + DNS 解析到部署机
  • 备案 + 真证书走 HTTPS，缺则退回 IP
  • 网关是可拆项，不装也能用
