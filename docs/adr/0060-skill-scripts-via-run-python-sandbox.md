# 0060 技能脚本经 run_python 沙箱执行：扩展双模，母本只读挂载

- 状态：Accepted
- 日期：2026-11-20
- 关联：ADR-0004（技能账户级、渐进披露）、ADR-0046（红线「无通用命令执行面」）、ADR-0056
  （run_python 隔离沙箱，本票复用其围栏）、ADR-0052（子 run 只读白名单）、ADR-0027（恒确认先例）、
  ADR-0033（docs 新建免二次确认）、CONTEXT「技能」「Python 沙箱」

## 背景

技能 v1 刻意只消费指令性内容：`scripts/` 拒读、脚本不可执行（user-skills spec 故事 11 / 范围外）。
当时的前提是「Agent 无 shell 工具」，拒读是「无执行能力」的配套双保险。其它平台的技能普遍带
Python 等可执行脚本，用户问「我们是不是没办法这么做」。

ADR-0056 落地后前提已变：平台有了隔离 Python 沙箱（一次性容器、工作区只读、写只进 scratch、
非 root、限资源、当前 `--network none` 离线）。技能脚本可以接进这条现成通道，而不必新开执行面。
红线（ADR-0046/0056）保护的是「围栏不可绕过」，不是「禁止执行」——技能脚本仍在同一个隔离沙箱里跑，
不新增通用 shell，红线不动。

## 决策

1. **扩展 `run_python` 为双模，不立新工具**。code 模式（源码字符串）不变；新增 skill 模式
   （`skill_dir` + `script` + 可选 `argv`），二者互斥。复用沙箱全部安全口径、确认链、产物扫描，
   避免两个沙箱入口同步维护资源/安全口径。
2. **单技能目录只读挂载 `/skill:ro`，跑母本原件**。不挂整个技能根（避免跨技能读面）；脚本改不了
   技能母本（只读挂载），产物仍走 scratch → `write_file` 落盘围栏。
3. **确认沿 `CONFIRM_WRITE` 档**（受 `agent.write_confirm` 控制，与文件写入同级，零新增配置）。
   用户拍板沿用开关而非恒确认：沙箱隔离（只读工作区、离线、无凭据、scratch 临时）是主安全网，
   确认卡是可见性闸，与「跑模型自己写的代码」同级即可。
4. **读面放开 `.py`（含 `scripts/`）**，删 `is_skill_scripts` 守卫。用户拍板放开而非保持拒读：
   模型可先读源码再执行、出错对照修。story-11 双保险中「拒读」一支退役，「围栏/只读/文本白名单」
   仍在；二进制、越界、200KB、写面不开不变。
5. **纯标准库离线**。沙箱当前 `--network none`（ADR-0056 预留的 005 网络出口未落地），第三方库
   import 失败是正常结果；依赖加宽待 005，不在本票。
6. **子 run 不开放**：`SUBRUN_TOOL_NAMES` 不含 `run_python`，沿用 ADR-0052 只读语义，白名单不改。
7. **围栏复用 `resolve_skill_path`，不开第二读面**；`argv` 以 docker exec 形直传，无 shell 拼接，
   无命令注入面；argv 限 ≤32 个、单个 ≤2000 字符。

## 备选方案

- **新工具 `run_skill_script`**：语义清晰、run_python 不动，但要钉四处工具清单、新 prompt 块、
  前端新卡，且沙箱调用/产物扫描与 run_python 大量重复，两入口须同步维护安全口径。被否（取扩展）。
- **只放开读面，模型读源码喂 `code`**：零沙箱改动，但跑的不是母本原件（转抄可能改样/截断），
  大脚本吃上下文，确认卡也看不出在跑技能。被否（保真差）。
- **恒确认（CONFIRM_ALWAYS）**：对齐 db_write 不可回滚先例，但用户选沿用写入开关；沙箱隔离已封死
  写工作区/凭据/网络渗出，恒确认打断迭代。被否（用户拍板）。
- **保持 `scripts/` 拒读**：改动最小、守卫不动，但模型不能对照源码调试。被否（用户拍板放开）。
- **挂整个技能根**：省一次路径推导，但打开跨技能读面。取单技能目录只读挂载。

## 后果

- **story-11 测试钉改写**：`scripts/.py` 从「拒读」改「可读」，二进制/越界仍拒；run_python schema
  required 由 `["code"]` 清空（互斥 handler 判），相关工具清单钉同步。
- **红线不变**：仍是隔离 Python 沙箱，非通用 shell；ADR-0046/0056 的围栏保护语义原样成立。
- **渗出面同 ADR-0056**：只读挂载 + 当前离线，无公网渗出（直到 005 加宽网络）；deploy 凭据、
  应用库凭据、平台库、docker.sock 均不可触达。
- **挂载权限是实现期风险**：容器 uid 1000 须可读技能目录，Linux 上验证，必要时挂载前 `a+rX`
  （只读挂载仍挡写，不改母本只读语义）。
- **取代关系**：user-skills spec 故事 11、「脚本执行」口径、范围外「脚本执行」条目由
  `docs/specs/2026-11-20-skill-script-execution.md` 取代；其余技能口径不变。
