# 0059 聊天流视觉语言：克制对话流 + 过程聚合投影 + 卡片两档外壳

- 状态：Accepted
- 日期：2026-11-19
- 关联：ADR-0029（本 ADR 澄清其同构不变式的边界）、ADR-0055 / ADR-0058（颜色体系底座与登录页豁免）、
  CONTEXT「聊天页侧栏」「中栏」

## 背景

聊天页是用户唯一日常停留的界面，但视觉语言各自为政：13 张卡片圆角混用 4/6/8/999，内距混用
1/2/3/4/5/6/8/10/12，中栏字阶混用 8 档（10 / 11 / 12 / 12.5 / 13 / 14 / 15 / 30 px）。换肤分支
`feature/console-theme` 已建成 73 个语义颜色变量 × 浅深两套，但**几何层（字阶 / 间距 / 圆角 /
阴影）token 一个都没有**。

同时消息流把思考块与工具行按发生顺序平铺，一屏常见 6 条「查看思考」灰条 + 4 行裸工具名，
真正的正文被淹没在最底下。

## 决策

1. **视觉标尺＝克制对话流**（Claude / ChatGPT 式）：大留白、弱边框、正文优先、过程极淡。
2. **基线＝先合 `feature/console-theme` 回 master**，站在已有的 73 个语义颜色变量上做，
   不重做颜色体系。
3. **过程聚合＝消息流的纯投影**：相邻思考块与工具行折成一组摘要（「思考 · N 个工具」），
   展开看原样。分组规则实时与历史**共用同一套**，不引入实时独有的状态。
4. **澄清 ADR-0029 的边界**：同构不变式约束的是**消息序列**，既不禁止分组投影，也不约束
   折叠态。按 `streaming` 分档折叠是既有做法（`ThinkingBlock.vue:9` 的 `open = ref(props.streaming)`）。
5. **耗时 / 时间戳刻意不做**：`created_at` 在 `messageModel.js:51` 被刻意丢弃，实时与历史都
   重建不出耗时；ADR-0029 规定不可重建字段不得参与已答态渲染。摘要只给**可数的计数**，不给秒数。
6. **运行中最后一组展开、历史组折叠**，沿用 ThinkingBlock 的 `streaming` 判据。折叠时机
   **不得拿 `message_done` 当「执行结束」**——它的语义是「本轮输出收口」，一次执行发多次
   （ADR-0029 后果第 1 条）。
7. **卡片统一外壳 `ChatCardShell`，两档变体**：`interactive`（提问 / 确认 / 委派——保留可辨
   边框与状态底色，防漏答）、`readonly`（预览 / 走查 / 抓取 / 下载 / 工具——一根细线、无底色）。
8. **新增几何 token 层**（字阶 / 间距 / 圆角 / 阴影），**与主题无关、浅深共用**；`DESIGN.md`
   作为可校验契约，承载 token 表、Do/Don't 与卡片两档规则。
9. **范围＝中栏全量**（消息流 / 13 张卡 / 输入框 / 应用操作条 / TodoBar / 提问导航条）；
   左右两翼只对齐几何节奏，不改结构。
10. **验收＝改前截图基线 + 改后同角度对比 + 真实长会话人工走查 + 几何 token 的 lint 式断言**
    （中栏不得出现裸 px 字号 / 圆角）。

## 备选方案

- **只做 CSS 弱化不动结构**：测试几乎不动、最省，但一屏仍是十行噪声，信噪比只改善不解决。被否。
- **聚合 + 后端补耗时**：草图能原样落地，但要动存储与投影、老会话缺数据要有降级态、
  `test_ws` 帧断言跟着改。被否。
- **只收语义变量不抽组件**：省，但一致性靠人维持，新增卡片继续漂。被否。
- **单一弱线形态（全部卡片无底色）**：最彻底的克制，但提问 / 确认卡失去视觉召唤，用户可能漏答。被否。
- **三栏全量重做**：SideBar 599 + 582 行测试、FilePanel 287 + 352 行测试全进范围，工作量约翻倍。被否。
- **只建 DESIGN.md 不新增变量 / 都不建直接改值**：规范无强制力，或这次统一完下次即漂，
  「设计体系」这半个目标落空。被否。
- **自动像素 diff 阈值**：流式内容与随机数据让噪声极大，阈值调不动，维护成本高。被否。
- **Linear / Vercel 精密控制台**：长文阅读更挤。**Cursor / Windsurf IDE 对话**：与「默认浅色」
  基调冲突。**沿用蓝灰基调精修**：无外部标尺，「好看」难客观验收。三者均被否。

## 后果

- `ChatMessages.test.js`（938 行）大面积重钉；13 张卡各自的 `.test.js` 结构与类名断言跟着动。
- 中栏组件模板全部改为消费 `ChatCardShell` 与几何 token；**此后新增卡片必须走外壳**，
  否则一致性立刻破。
- 几何与颜色分层：颜色随 `data-theme` 换，几何不换。新增样式要同时想「哪个颜色变量 + 哪个几何档位」。
- 自动滚底逻辑要适配「运行中展开组的高度持续变化」。
- 不做耗时意味着摘要永远只有计数。将来若要秒数，**必须先改存储与投影**，不能只改前端。
- 合并前置：`feature/console-theme` 与 master 的冲突面只有 `LoginView.vue` 一个文件；主工作区
  未跟踪的 `docs/adr/0055` 与分支已提交版字节一致，**合并前不得改动它**（见 ADR-0058）。
