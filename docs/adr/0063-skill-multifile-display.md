# 0063 技能多文件展示：只读详情抽屉 + 快照式安装预览 + 图片预览面

- 状态：Accepted
- 日期：2026-11-20
- 关联：ADR-0004（技能账户级、母本对 Agent 只读）、ADR-0060（技能脚本经沙箱执行，展示需跟上
  多文件+可执行事实）、ADR-0056（run_python 沙箱，回执卡）、CONTEXT「技能（skill）」元数据/母本两层

## 背景

技能早已是整目录多文件包（SKILL.md + references/assets + scripts，上限 600 文件/10MB），
ADR-0060 又让 scripts 可经沙箱执行。但技能管理页（`SkillsView.vue`）仍只展示一行元数据
（名称/描述/来源/启用/删除），后端 `list_skills` 只回 DB 行，**没有任何文件清单/内容接口**。
用户看不见技能内部有哪些文件/脚本，无法在安装后、执行前审视自己装了什么（尤其第三方 GitHub
技能）。展示要跟上「技能≠单个 readme」的事实。

## 决策

1. **展示分元数据/母本两层，四面升级**：A 管理页列表增强（名称下副信息「N 文件 · X KB ·
   含脚本」，不新增列）；B 技能详情（右侧抽屉，左文件树右内容预览）；C 安装前预览（两段式）；
   D 对话回执（RunPythonCard 区分技能脚本，script 字段已回）。
2. **详情/预览只读，不开管理页写面**。与 ADR-0004 母本对 Agent 只读一致，平台展示侧同样
   只读浏览、不改/删单文件。深度＝结构+可读内容（SKILL.md 渲染、scripts 源码、references 文本）。
3. **安装预览两段式 + 快照一致性**：URL/GitHub 通道先 preview 拉取整包暂存（token→包，TTL
   清理），回文件清单+内容供审视，确认 install 从**快照**落盘——preview==install，防 upstream
   变化/调包。与 AI 草稿（generate→adopt）同构人在环。体积沿现有 10MB/600 上限。
4. **图片二进制预览面**：文本沿 Agent 受控读面白名单（.md/.txt/.json/.csv/.yaml/.yml/.py）；
   图片类（png/jpg/jpeg/webp/gif）经类型围栏的二进制端点内联预览；其它二进制仅列名/大小/类型。
5. **后端文件接口复用技能受控读面围栏 + owner 隔离**：列目录/读文本/读图片均按
   `request.state.actor` 归属过滤，路径收敛到 `skills_root`（复用 `resolve_skill_path` 语义），
   越权 404，不开第二读面。

## 备选方案

- **详情独立页 / 模态框**：空间大或合弹框惯例，但离开列表 / 双栏局促。取右侧抽屉（窄栏管理页
   不离开列表，合 ant-design-vue 组件）。
- **装后详情复用 B（零安装流改动）**：最轻，审视仍在执行前（母本只读不执行），但用户选装前
   两段式预览——trust-before-land，装前即可审视第三方脚本再决定装不装。
- **安装重新拉取 / 前端持包回传**：前者预览与安装可能不一致（信任语义弱），后者多文件大包传
   两遍且回传需校验。取快照（preview==install）。
- **二进制仅元数据 / 全部可下载**：前者看不见 assets 图，后者扩大母本外发面。取图片可预览
   （类型围栏收口）+ 其它仅元数据。
- **管理页可编辑单文件**：能力最强但开新写面，与只读口径冲突，需确认/回滚围栏。本期否。
- **列表新增独立列**：窄栏（960px、现 5 列）更挤。取名称下副信息。

## 后果

- **安装通道改两段式**：GitHub/URL 通道加 preview 接口与快照暂存（TTL 清理）；install 消费
   快照而非重新 fetch。AI 通道已是两段式，口径对齐。
- **新图片二进制端点是新的母本流出面**：类型围栏 + owner 隔离 + 只读；文本沿白名单。红线不动
   （无通用执行面，展示只读）。
- **list 接口补聚合字段**（文件数/总大小/含脚本标记）：扫母本目录或落库聚合，实现期定口径。
- **前端**：SkillsView 列表副信息 + 详情抽屉（文件树+文本预览+图片预览）+ 安装预览态；
   RunPythonCard 区分技能脚本标题/脚本名。
- **术语沉淀**：CONTEXT「技能」节补元数据/母本两层与「技能详情」定义。
